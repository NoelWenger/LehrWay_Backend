How to close Issues via command Line in GIT-BASH.

V. Luka
---

Step 1)

$ git add .

Step 2)

$ git commit -m "<kommentar> <befehl> #<nummer>"

Bsp.

$ git commit -m "Added example.txt closes #5"

<kommentar> ==> Dein Kommentar
<befehl> ==> Eines der Befehle (siehe unten)
<nummer> ==> Issue Nummer

Step 3) 

$ git push
